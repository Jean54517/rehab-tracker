# rehab-tracker
一个基于 HTML、CSS 和 JavaScript 的个人疼痛与康复追踪工具，无需服务器或账号即可在浏览器中运行。

主要功能：
- Pain tracking：记录每日疼痛情况及身体部位。
- Activity tracking：记录步数和其他运动。
- Rehabilitation training：记录康复动作、组数、次数、重量、训练时长和 RPE。
- Training templates：保存和调用不同身体部位的康复训练模板。
- Sleep tracking：记录每日睡眠时长。
- Sitting & standing tracking：记录久坐、久站时长，支持分段累加或直接填写当天总时长。
- Trend analysis：通过图表分析疼痛、活动、睡眠和久坐久站之间的变化关系。
- Data export：支持 JSON 备份和 CSV 导出。
  
技术特点：
- 纯前端网页，无需后端服务器。
- 使用浏览器 Local Storage 保存数据。
- 支持本地运行，也可以部署到 GitHub Pages。
